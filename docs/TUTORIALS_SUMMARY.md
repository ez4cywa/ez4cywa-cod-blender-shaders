## 教程地图

### 基础与实战

- **《从 COD 贴图到 Blender 材质》**（24 章）— 项目主教程。第 1–12 章用武器讲基础：读通道（47 号 albedo / 48 号 NOG）、五节点顶层接线、`1-R` 粗糙度候选、半八面体法线解码、错误对照实验；第 13–18 章扩展到 Dallas 人物（皮肤 SSS、发片、眼部与装备分类材质）；第 19–24 章为瞄准镜薄壁玻璃 v11（在本仓库独立成篇）。对应节点组：`COD_Weapon_Master_v1`、`COD_Decode_HemiOct_NOG_v1`、`COD_Character_Surface_v1`、v11 玻璃组。
- **《瞄准镜薄壁玻璃 v11》**（本仓库独立成篇）— 薄片与重合层辨认、黑色镜片通道误区（Tint 独立近白）、`Glass Mode` 统一入口开关、Thin Wall/透射/法线链、污渍与纳米镀膜分开控制、固定机位验证边界。对应节点组：`COD_Optic_Glass_Master_v1`、`COD_Master_Surface_v11`。含三张接线图；通道图与受控对照渲染图留在私密研究仓库。
- **《Blender 节点连线：从一张贴图到完整画面》**（10 章）— 通用节点思维：插口类型与自动转换陷阱、法线/高度/置换的区别、Principled 逐参数用法、Mix 与 Add Shader 选型、合成器降噪与排错表。不绑定具体资产，适合打基础。
- **《Blender 5.2.2 全渲染节点参考》**（280 个节点条目）— 工具书。每个节点五段式条目：做什么 / 怎么连 / 项目用法 / 常见错误 / 插口类型，覆盖 Shader Editor 与 Compositor 全部可创建节点，并标注 5.x 版本变化。

### 迷彩专题

- **《把迷彩贴到枪身上：分层 Shader 实战》**（11 章）— 逐槽位核对 rex_camo_special_01 的 9 张原图，三层结构（底纹/重复文字/胶带贴纸）独立定位、覆盖与露底控制，Empty 平面投影定位系统与错误接线对照。对应节点组：`COD_Camo_Layer_v1`、`COD_Camo_Coordinates_v1`。
- **《资产记录与迷彩 Shader v3》**（6 章）— 进阶逆向：从 `global_stream_mp.ff` 定位迷彩资产记录，11 个图像引用逐槽哈希一致，恢复真实迷彩普通分支的参数平方颜色数学 `L = SampleColor × c × c` 与双 UV 候选对照。对应节点组：`COD_Game_Camo_Color_v3`、`COD_Camo_Layer_v3`。

### 游戏渲染机制（v2 起的原理链）

- **《从本地游戏程序到 Blender Shader v2》**（9 章）— 方法论核心教程：离线解包 11 个基础 FF、用微软 DXC 解析 2,696 个 DXIL 程序、区分「程序事实 / 资源假设 / Blender 近似」三层证据；恢复 G/A 编码前缩放、光泽数据链 `R × scale + bias` 与迷彩坐标严格运算顺序 `q = S0×(S1×(uv-0.5+k·d)+0.5)`。对应节点组：`COD_Game_NOG_Decode_v2`、`COD_Game_Camo_UV_v2`、`COD_Weapon_Master_v2`。
- **《法线叠加实验室 v4》**（6 章）— 游戏式法线叠加数学：先逐层累积 XY、最后用 `z = 1 - 0.6*(x²+y²)` 重建 Z（非 sqrt 式），Layer 组可串联、Finish 组只接一次，不偷跑夹紧与归一化。对应节点组：`COD_Game_NormalXY_Layer_v4`、`COD_Game_NormalXY_Finish_v4`。
- **《UV 方向基与迷彩法线 v5》**（6 章）— 把迷彩层法线接入真实网格：双 UV 方向基矩阵推导、`B = sign*cross(N,T)` 手性处理、`codv5_paint_row0/row1/valid` 属性桥接与失效检测。对应节点组：`COD_Packed_Matrix_RGBA_v5`（含 v4 Layer/Finish 复用）。

### 几何恢复（v6 → v10）

- **《分页矩阵与插值 v6》**（5 章）— 分页几何缓冲的矩阵寻址公式（128 字节记录 / 1024 字节页 / 16 位索引重排）与关键结论：矩阵插值后**不做归一化**，强行归一化会放大法线偏移两倍。对应节点组：`COD_Matrix_Linear_Interpolate_v6`。
- **《压缩索引到法线 v7》**（5 章）— 压缩三角形位流解码工具链：编号位宽、符号幅度差值（非补码）、跨字跨页读取、16 位重排表，接 Blender 角点法线着色。对应节点组：`COD_Corner_Matrix_Normal_v7`。
- **《从缓存追到贴图 v8》**（5 章）— 数据来源闭环示范：CDN 缓存与 XPAK 索引解析、460 次 BC1–BC7 解码尝试中唯一一条全像素精确匹配（Key `4da2d0ddcc0fb619` ↔ 导出 PNG，SHA-256 一致）。本轮不新增 Shader 接线。
- **《从包索引读出真实对象 v9》**（5 章）— 基础设施教程：XSUB 包索引定位公式 `offset = (PackedInfo>>32)*128`、两种读取路径实测（936725 条索引 / 1307 抽样对象）、名称命中≠模型绑定的边界声明。本轮不新增 Shader 接线。
- **《把真实切线框架接回 Shader v10》**（9 章，系列最长）— 核心实战成果：首次从真实包对象恢复 QTangent 框架（97 网格 / 107 UV 层 / 170657 顶点全核对），bit 29 符号不插值、混合符号面保守回退，T/N/B 插值后统一归一化。对应节点组：`COD_Recovered_TBN_v10`、`COD_Static_Frame_Candidate_v10`，属性 `codv10_T/N/sign/valid`。

### 验证记录（方法论样板）

- **《实施与验证记录》** — 项目总验收：官方 Blender 固定版本 + SHA-256 校验、426 个源文件逐文件哈希、12 份 blend 相对路径检查、数值探针阈值体系、远程全新克隆恢复。
- **《迷彩扩展验证记录》** — 单项验收样板：输入哈希留档、重复构建数量稳定性、8 组发光探针误差 0.000980392、Strength=0 与原 Shader 逐像素一致、远程重建与本地逐像素一致。

## 贯穿始终的方法论

1. **证据分层**：程序事实（可证实）→ 资源假设（候选）→ Blender 近似（实现），三层严格分离，绝不把候选说成已验证。
2. **数值探针**：每个 Shader 交付都附带 Cycles 32 位线性 EXR 探针，误差普遍控制在 1e-5 ~ 1e-8 量级。
3. **单因素对照**：所有效果图使用受控实验（同一几何、同一光照、只改一个参数），拒绝"更好看"式调参。
4. **诚实边界**：每个版本明确声明"已完成 / 仍是候选 / 尚未恢复"，未知槽位保留不启用。
